# Rukshan Amodya - Developer Portfolio

Responsive interactive developer portfolio crafted for the **Internet Technology** module coursework at the Institute of Computer Engineering Technology (iCET).

## Features
- **Modern Dark Aesthetic**: Deep sleek obsidian theme with responsive design tokens.
- **Interactive Ripple Hero Grid**: High-frequency interactive canvas grid responding to mouse clicks and cursor hover.
- **Dual Infinite Marquee**: Dynamic opposite-direction scrolling skill marquees.
- **Project Showcase**: Rich interactive project cards with direct GitHub links and live modal lightbox.
- **Timeline Milestones**: Alternating educational and career roadmap.
- **GitHub Live API**: Real-time GitHub repositories and profile statistics integration.
- **Pure HTML5, CSS3, & Vanilla JavaScript**: Zero dependency runtime adhering to coursework specifications.
